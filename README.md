# Оперативные влагалищные роды — КР РОАГ 2023

PWA для родблока по КР «Оперативные влагалищные роды» (РОАГ, 2023, ID 775): выбор метода (ВЭП / АЩ / КС), таймер и счётчики операции с критериями неуспеха, послеоперационный чек-лист, код МКБ-10, протокол с копированием и печатью в PDF, справка по технике.

## Публикация на GitHub Pages
1. Создать репозиторий (например, `ovr`) и загрузить все файлы из архива в корень.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
3. Через 1–2 минуты: `https://<username>.github.io/ovr/`

## Установка на телефон
- iPhone: Safari → «Поделиться» → «На экран Домой».
- Android: Chrome → меню → «Установить приложение».

После первого открытия работает офлайн. Данные хранятся только в браузере устройства.

## Обновление
После правки `index.html` увеличить версию `CACHE` в `sw.js` (`ovr-v1` → `ovr-v2`).

Вспомогательный инструмент, не заменяет клиническое решение врача.
